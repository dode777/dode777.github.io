Bible On Air

A scripture prompter for services and gatherings

A Windows prompter that puts the passage you pick on a second screen in large type. One portable file, no installation.

Coming soonGitHub repository

The first public release is being prepared.

Overview

Built for services, small groups, and retreats — anywhere a passage needs to go up on the front screen. Pick a book, chapter, and verse on your laptop, and the text goes full screen on the projector or second monitor.

The scripture text ships inside the app, so it works without an internet connection. During a service you move through verses with the arrow keys alone.

Features

  • Dual-screen output

    Choose an output display from the list of connected monitors. Controls stay on your laptop while only the passage goes full screen up front.

  • Three display modes

    Continuous scroll, one verse at a time, or slide-plus-scroll — pick whichever matches how the session runs.

  • Fast book search

    Type a few characters and the matching book is selected. Navigate results with the arrow keys and confirm with Enter.

  • Arrow-key control

    ↑ ↓ to scroll, ← → to move between verses. Hold Shift to jump a full page at a time.

  • Adjustable type size

    Font size runs from 30px to 200px so the text fits the room and the screen you are using.

  • Settings remembered

    Display, font size, mode, and reference visibility are saved and restored the next time you open the app.

Install and usage guide

  1. Download the executable

    Use the download button below to get the Bible Viewer executable from the GitHub releases page.

  2. Run it directly

    It is portable — there is no installer. Double-click the .exe to start. You can carry it on a USB drive and run it on another PC.

  3. Pick the output display

    Connect the projector or second monitor first, then choose the target screen under “모니터” at the top of the window.

  4. Set the passage range

    Choose a book and set the start and end chapter/verse. In slide mode you only need the starting point.

  5. Turn the screen on

    Press the button at the bottom right to send the passage to the selected display, then drive it with the arrow keys.

Frequently asked questions

Is there a macOS or Linux build?

Only a Windows executable is available right now. Other platforms are under review — let us know through the contact channel if you need one.

Windows shows an “unrecognised app” warning.

The build is not code-signed yet, so SmartScreen may warn you. Choose “More info → Run anyway” to continue.

Does it work offline?

Yes. The scripture text is bundled with the app, so no network connection is needed.

My projector is not in the monitor list.

Connect the cable before launching the app and make sure Windows display settings are set to “Extend”. In mirrored mode only one screen is detected.

Can I add another translation?

The app currently ships with a single bundled Korean text. Additional translations are under consideration.
