Overview

Ever had to find and put a verse on screen in the middle of a service?

An unexpected reading need not throw you. Bible OnAir sends the passage out in a few keystrokes.

Key features

  • Simple output setup

    Choose the display the passage goes to — a second monitor or a projector — in a couple of clicks.

  • Fast passage selection

    Select book, chapter and verse in turn to set the range. A search shortcut (Ctrl + F) is available as well.

  • Several display modes

    One verse, several verses, or continuous scroll — pick whichever suits the moment in the service.

  • Stage and switch

    A single key switches between sending the passage out and holding it back.

  • Favourites and backup

    Register the passages you use often and recall them instantly. Import and export the list as JSON to back it up or share it.

  • Automatic updates

    New features and releases are announced and installed automatically.

Bible OnAir(바이블온에어) in use

  • Control window — select a passage on the left, preview the output on the right.

  • Output screen — the selected passage, large on the projector or second monitor.

  • Broadcast captions — switch the output to captions and send them to software such as vMix.

  • Caption overlay — just the caption band on a transparent background, laid over the video. (Background is illustrative.)

  • Favourites — keep the passages you use often and recall them in one click.

  • Screen settings — choose the display mode, type size and output monitor.

  • Caption settings — set type size, position and background opacity, with vMix setup steps.

Frequently asked questions (FAQ)

Windows shows an "unrecognised app" warning.

The program is safe to install. This is an early release and code signing is still being registered, so Windows blocks it temporarily. [How to install] Click [More info] in the warning dialog, then press the [Run anyway] button that appears.

Is there a macOS or Linux build?

Bible OnAir currently supports Windows only. Support for further platforms is under review.

My projector is not in the monitor list.

Check whether the display setting is set to "Duplicate". In duplicate mode Windows sees a single monitor, so the projector does not appear in the list. Right-click the desktop ➔ [Display settings], or press Win + P, and switch the mode to [Extend].
