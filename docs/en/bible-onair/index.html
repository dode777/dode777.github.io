Bible OnAir

A scripture prompter

Select a book, chapter and verse on your laptop and it is displayed on the projector.

Download for WindowsAll releases

Bible-OnAir-Setup-1.0.0.exe

Overview

For putting scripture on the front screen during a service or meeting. The control window stays on your laptop; only the passage goes out.

It works without an internet connection, and tells you when a new version is out.

Key features

  • Dual-screen output

    Connect the projector, then designate the output display. The list refreshes when monitors are connected or removed.

  • Book → chapter → verse

    Select book, chapter and verse in turn to set the range. Ctrl+F searches all 66 books.

  • Three display modes

    One verse, a few verses, or continuous scroll. Long verses are scaled automatically to fit the screen.

  • Staged output

    Stage the next passage in advance and send it with the O key. The Q key blanks the output screen.

  • Favourites

    Register frequently used passages for immediate recall. Export them as JSON to transfer to another PC.

  • Automatic updates

    New releases are announced and installed from within the app.

Frequently asked questions

Is there a macOS or Linux build?

Windows only at present.

Windows shows an "unrecognised app" warning.

Choose "More info", then "Run anyway". The build is not code-signed yet.

My projector is not in the monitor list.

Set Windows display settings to "Extend". In mirrored mode only one screen is detected.
