손짓으로 챙기는 하루

웹에서 열기

doit.isocompany.co.kr

휴대폰이나 태블릿에서 열어주세요. 컴퓨터에서는 QR 코드가 나옵니다.

소개

매일 먹는 약, 잊기 쉬운 루틴, 달마다 빠져나가는 고정비. 챙길 것은 많은데 체크리스트는 금방 길어집니다.

Do-It은 한 화면에 한 가지만 보여줍니다. 꾹 눌러 완료하고, 위로 넘겨 다음 것을 챙기면 됩니다. 놓친 것을 빨갛게 쌓아 재촉하지 않습니다.

주요 기능

  • 꾹 눌러 완료

    버튼을 찾을 필요 없이 화면을 꾹 누르면 완료됩니다. 다시 꾹 누르면 되돌리고, 횟수 목표는 누를 때마다 하나씩 올라갑니다.

  • 한 줄로 추가

    두 번 탭하고 "스쿼트 주 3회", "넷플릭스 매월 25일 17000원"처럼 적으면 시간대·횟수·금액을 알아서 나눠 넣습니다.

  • 주제별로 넘겨보기

    약·영양제, 루틴, 집안일처럼 주제를 나눠 옆으로 넘깁니다. 같은 주제 안에서는 위아래로 한 장씩 챙깁니다.

  • 간격과 기한

    칫솔 교체처럼 며칠마다 하는 일, 자동차 검사처럼 날짜가 정해진 일도 때가 되면 나타납니다.

  • 고정비 한눈에

    구독·보험·통신비를 분류별로 모아 한 달 합계와 다가오는 결제일을 보여줍니다. 해지하기로 한 것은 따로 표시합니다.

  • 설치 없이 앱처럼

    앱스토어를 거치지 않고 브라우저에서 바로 엽니다. 홈 화면에 추가하면 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

Do-It 사용 예시

  • 한 화면에 하나 — 지금 챙길 것만 크게 보입니다.

  • 꾹 누르면 완료 — 다시 꾹 누르면 되돌립니다.

  • 두 번 탭해서 한 줄로 추가 — "저녁 루테인 1알"처럼 적으면 알아서 나눕니다.

  • 끌어내리면 오늘 요약 — 주제별 남은 것과 고정비 합계를 한눈에.

홈 화면에 추가하기

  1. 휴대폰에서 열기

    위의 "웹에서 열기"를 누르거나 doit.isocompany.co.kr 로 들어갑니다. 카카오톡·인스타그램 안에서 열렸다면 오른쪽 아래 메뉴에서 기본 브라우저로 열어주세요.

  2. 아이폰 (Safari)

    아래쪽 공유 버튼을 누르고 [홈 화면에 추가]를 고릅니다.

  3. 안드로이드 (Chrome · 삼성 인터넷)

    오른쪽 위 메뉴(⋮)에서 [홈 화면에 추가] 또는 [앱 설치]를 고릅니다.

Releases

새 버전은 따로 설치할 필요 없이, 앱을 다시 열면 자동으로 적용됩니다.

  1. v0.1.3최신 버전2026-09-25

    시작 화면과 화면 위쪽을 다듬고, 링크 공유 미리보기를 넣었습니다.

    변경 내용 자세히 보기
    • 시작 화면을 더 여유 있게 보여줍니다. 로고가 서서히 나타났다가 서서히 사라지고, 처음에 로고가 잠깐 번쩍이던 것을 없앴습니다.
    • 홈 화면에 추가한 앱이 시계·배터리가 있는 맨 위까지 화면을 채웁니다. 이미 추가했다면 다시 추가해야 적용됩니다. 아이폰은 홈 화면 아이콘을 지우면 기록도 함께 지워지니, 먼저 설정에서 기록을 파일로 내보낸 뒤 지우고 다시 추가하고, 파일에서 가져오기로 되돌려 주세요.
    • 화면을 가로로 돌렸을 때 시작 화면이나 주제 화면이 반쯤 걸쳐 보이던 문제를 고쳤습니다.
    • 앱 주소를 카카오톡이나 문자로 공유하면 Do-It 소개 그림과 설명이 함께 보입니다.
  2. v0.1.22026-09-24

    더 앱처럼 동작하도록 다듬었습니다.

    변경 내용 자세히 보기
    • 설정 같은 창이 떠 있을 때 화면이 옆으로 끌려 밀리던 문제를 고쳤습니다.
    • 두 번 탭하거나 두 손가락으로 벌려도 화면이 확대되지 않습니다.
    • 안내 문구를 길게 눌러도 글자가 선택되지 않습니다. 입력창에서는 그대로 쓸 수 있습니다.
  3. v0.1.12026-09-24

    시작 화면을 다듬었습니다.

    변경 내용 자세히 보기
    • 앱을 열 때 나오는 시작 화면을 조금 더 여유 있게 보여줍니다. 탭하면 바로 넘어갑니다.
    • 시작 화면이 사라진 뒤 화면 아래쪽에 색이 남던 문제를 고쳤습니다.
  4. v0.1.02026-09-24

    Do-It이 출시되었습니다.

    변경 내용 자세히 보기
    • 한 화면에 할 일 하나씩 보여줍니다. 꾹 눌러 완료하고, 다시 꾹 누르면 되돌립니다.
    • 두 번 탭해서 한 줄로 추가합니다. "저녁 루테인 1알", "넷플릭스 매월 25일 17000원"처럼 적으면 시간대·횟수·금액을 알아서 나눠 넣습니다.
    • 약·영양제, 루틴, 간격, 목표처럼 주제를 나눠 옆으로 넘기고, 같은 주제 안에서는 위아래로 한 장씩 챙깁니다.
    • 구독·보험·통신비 같은 고정비를 분류별로 모아 한 달 합계와 다가오는 결제일을 보여줍니다.
    • 상단 제목을 끌어내리면 오늘 요약이 나옵니다. 시간대 시각과 손짓 안내도 여기서 바꾸고 다시 볼 수 있습니다.
    • 설치 없이 휴대폰 브라우저에서 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
    • 기록은 휴대폰 안에 저장됩니다. 설정에서 파일로 내보내 백업하고, 기기를 바꿀 때 다시 불러올 수 있습니다.

자주 묻는 질문(FAQ)

앱스토어에서 받을 수 있나요?

지금은 웹앱으로만 제공합니다. 브라우저에서 열고 홈 화면에 추가하면 앱 아이콘이 생기고, 주소창 없이 앱처럼 열립니다.

컴퓨터에서도 쓸 수 있나요?

Do-It은 꾹 누르기, 두 번 탭, 밀기 같은 손짓으로 쓰는 앱이라 휴대폰과 태블릿만 지원합니다. 컴퓨터에서 열면 휴대폰으로 옮겨 열 수 있는 QR 코드가 나옵니다.

홈 화면에 추가 메뉴가 보이지 않습니다.

카카오톡이나 인스타그램 같은 앱 안의 브라우저에서는 이 메뉴가 없습니다. 아이폰은 Safari, 안드로이드는 Chrome 이나 삼성 인터넷으로 다시 열어주세요.
