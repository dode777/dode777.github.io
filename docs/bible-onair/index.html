Bible On Air

바이블온에어

예배와 모임을 위한 성경 프롬프터

성경 구절을 골라 두 번째 화면에 큰 글씨로 띄우는 윈도우용 프롬프터입니다. 설치 없이 실행 파일 하나로 씁니다.

준비 중GitHub 저장소

첫 정식 릴리스를 준비하고 있습니다.

소개

예배, 소그룹, 수련회처럼 앞 화면에 성경 본문을 띄워야 하는 자리를 위해 만들었습니다. 노트북에서 책·장·절만 고르면 빔프로젝터나 보조 모니터에 본문이 전체 화면으로 나갑니다.

성경 본문은 프로그램 안에 들어 있어서 인터넷 연결 없이도 동작합니다. 진행 중에는 방향키만으로 다음 절, 이전 절을 넘길 수 있어 조작할 사람이 따로 필요하지 않습니다.

주요 기능

  • 듀얼 모니터 송출

    연결된 모니터 목록에서 출력 화면을 고르면, 조작 화면은 노트북에 두고 본문만 앞 화면에 전체 화면으로 띄웁니다.

  • 세 가지 표시 모드

    연속 스크롤, 한 절씩 슬라이드, 슬라이드+스크롤 중에서 진행 방식에 맞는 모드를 고를 수 있습니다.

  • 빠른 책 검색

    “디모”, “데살”처럼 앞 글자 몇 개만 쳐도 해당 성경책이 바로 잡힙니다. 방향키와 Enter로 선택합니다.

  • 방향키 진행

    ↑ ↓ 로 스크롤, ← → 로 절 이동. Shift를 함께 누르면 페이지 단위로 크게 넘어갑니다.

  • 글자 크기 조절

    30px에서 200px까지 폰트 크기를 바꿀 수 있어 화면 크기와 자리 배치에 맞게 조절됩니다.

  • 설정 자동 저장

    모니터, 폰트, 모드, 장/절 표시 여부 등 마지막 설정을 기억했다가 다음 실행 때 그대로 불러옵니다.

설치 및 사용 가이드

  1. 실행 파일 내려받기

    아래 다운로드 버튼으로 GitHub 릴리스 페이지에서 Bible Viewer 실행 파일을 받습니다.

  2. 바로 실행

    설치 과정이 없는 포터블 방식입니다. 내려받은 exe 파일을 두 번 눌러 바로 실행하세요. USB에 넣어 다른 PC에서 쓸 수도 있습니다.

  3. 출력 모니터 선택

    빔프로젝터나 보조 모니터를 먼저 연결한 뒤, 상단의 “모니터” 항목에서 본문을 띄울 화면을 고릅니다.

  4. 구절 범위 지정

    책을 고르고 시작 장/절과 끝 장/절을 지정합니다. 슬라이드 모드에서는 시작 지점만 정하면 됩니다.

  5. 스크린 켜기

    오른쪽 아래 “스크린 켜기”를 누르면 선택한 화면에 본문이 뜹니다. 이후에는 방향키로 진행하세요.

자주 묻는 질문

macOS나 리눅스에서도 쓸 수 있나요?

현재는 Windows용 실행 파일만 제공합니다. 다른 운영체제 지원은 검토 중이며, 필요하시면 문의 채널로 알려주세요.

설치했는데 “알 수 없는 앱” 경고가 뜹니다.

코드 서명 인증서를 아직 적용하지 않아 Windows SmartScreen이 경고를 표시할 수 있습니다. “추가 정보 → 실행”을 눌러 진행하시면 됩니다.

인터넷이 안 되는 곳에서도 되나요?

됩니다. 성경 본문이 프로그램에 함께 들어 있어 네트워크 없이 동작합니다.

모니터 목록에 빔프로젝터가 안 보입니다.

프로그램을 켜기 전에 먼저 케이블을 연결하고 Windows 디스플레이 설정에서 “확장” 모드인지 확인해 주세요. 복제(미러링) 상태에서는 하나의 화면으로만 인식됩니다.

다른 성경 역본을 넣을 수 있나요?

현재는 내장된 본문 한 종류로 동작합니다. 역본 추가는 검토 중인 항목입니다.
